Circles Packer is a WPF desktop application designed to optimize, calculate, and visualize the nesting of circular pieces onto rectangular sheets. 

By comparing two different packing arrangements — orthogonal and staggered — the tool helps minimize material waste and streamlines manufacturing workflows.

Key Features

• Flexible Configuration: Input custom dimensions for circle diameter, desired quantity, minimum spacing between parts, sheet dimensions, and safety margins.

• Dual Layout Previews: Instantly compare a standard grid alignment (Rectangular Cut) against a dense, staggered layout (Triangular Cut) through real-time visual previews.

• Efficiency Analytics: View instant material metrics for both nesting methods, including total sheets required, parts per sheet, and the final sheet's utilization percentage.

• Data Export: Export the exact (X, Y) center coordinates of every generated circle to an external data file, making it ready for CNC, laser cutting, or plotting systems.



Prerequisites

• .NET SDK (version 7.0 or higher recommended)

• Windows OS (supporting WPF desktop applications)
